# 回声英语 v1.0.0（第一版 MVP）

## 安装

1. 将 `EchoEnglish-v1.0.0-debug.apk` 复制到 Android 手机。
2. 在手机文件管理器中点击 APK。
3. 如果系统拦截，请允许该文件管理器“安装未知应用”。
4. 支持 Android 8.0（API 26）及以上版本。

这是 Debug 签名测试版本，适合个人试用，不建议直接发布到应用商店。

## 快速使用

1. 打开应用，允许通知权限，以便后台播放时显示媒体通知。
2. 点击“批量导入文件”，可一次选择多个 MP3/M4A/AAC/WAV/FLAC 与 SRT；也可以点击“导入文件夹”。
3. 文件名标准化后相同的音频和字幕会自动匹配，例如 `lesson_01.mp3` 与 `lesson-01.en.srt`。
4. 进入“设置”，选择固定时长或按字幕分段、5/10/15/20/30 秒、重复次数、播放速度和列表播放方式。
5. 点击播放列表中的音频开始复读。每段达到重复次数后自动进入下一段。
6. 播放页“定时”可选择 5～90 分钟；默认到点后等当前片段结束再停止。
7. 锁屏或切到后台后，Media3 前台媒体服务会继续播放。

## 已实现

- 批量选择文件、导入文件夹。
- MP3/M4A/AAC/WAV/FLAC 与 SRT 文件名自动匹配。
- UTF-8、UTF-8 BOM、GB18030 SRT 解析。
- 固定时长逻辑分段与按字幕时间轴分段。
- 每段 1/3/5/10 次或无限重复，自动进入下一段。
- 0.75x～2.0x 播放速度。
- SQLite 持久播放列表、字幕对应关系、片段进度和最近播放位置。
- SAF 持久 URI 授权，重新打开应用后无需重复导入。
- Media3 后台/锁屏播放、音频焦点、耳机断开暂停、媒体通知。
- 睡眠定时器，支持到点立即停止或当前段结束后停止。
- 播放列表顺序播放、单曲停止、列表循环。
- 分段算法、SRT 解析和文件名匹配共 6 项自动测试。

## 第一版限制

- 尚未在真实手机上完成兼容性测试；不同厂商的省电策略可能终止后台服务，需要在系统设置中允许后台运行。
- 系统媒体通知稳定支持播放/暂停；“上一段/下一段”主要在应用播放页操作，部分锁屏界面可能只显示系统默认媒体按钮。
- 多个字幕候选冲突时不会擅自匹配，但第一版还没有手动重新绑定字幕的界面。
- 自定义秒数、自定义重复次数、拖动调整播放列表、列表搜索尚未加入。
- “当前音频结束后定时停止”尚未加入；当前支持分钟定时、立即停止或当前片段结束后停止。
- APK 使用 Debug 证书签名；正式发布需要生成独立 Release 密钥并构建 Release APK/AAB。
- 数据层采用 Android 原生 SQLiteOpenHelper，而不是 Room；持久化功能不受影响。
