# 回声英语 v1.2.0

## 本次修复

- 设置选项改为单层边框，移除 FilterChip 自带描边与额外描边叠加造成的双框。
- 重复次数为1时，跨分段不再执行 seek，音频沿同一条 ExoPlayer 时间轴自然连续播放。
- 重复次数大于1时，仅在尚需复读当前段时返回段首；最后一遍进入下一段时不再重复 seek。
- 默认字幕区恢复为只显示当前字幕，界面更简洁。
- 新增“展开字幕/收起字幕”，展开后可滚动浏览全部字幕并点击跳转。
- 展开状态下当前字幕自动滚动到可视区域中间附近；手动浏览时暂停跟随，并提供“回到当前字幕”。
- 默认字幕区域缩小，两个进度条分别标为“本段进度”和“总进度”，并增加进度条和播放按钮之间的间距。
- 保留总进度跳转、片段选择、即时设置、后台播放、播放列表保存和定时关闭等既有功能。

## 使用方法

1. 安装 `EchoEnglish-v1.2.0-debug.apk`。可覆盖安装旧测试版，正常情况下播放列表数据会继续保留。
2. 复读页默认只显示当前字幕；点击“展开字幕”可查看完整字幕列表。
3. 展开后点击任意字幕即可跳到对应时间。手动滚动后可等待自动恢复跟随，或点击“回到当前字幕”。
4. “本段进度”用于当前片段内跳转；“总进度”用于整条音频跳转。
5. 重复设置为1次时，分段仅用于显示和定位，播放过程不会在相邻边界强制跳转。
