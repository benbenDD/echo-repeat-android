# 回声复读 v2.0.4

回声复读是一款适用于语言学习、课程复习和音频精听的 Android 应用，支持持久化播放列表、批量导入 MP3/SRT、按固定时长或字幕分段、字幕书签、仅播放收藏字幕、分段重复、重复间隔、倍速播放、总进度与分段跳转、睡眠定时、媒体通知和锁屏后台播放。

## v2.0.4 更新

- 修复“仅播放字幕片段 + 单曲循环”运行期间切换到“仅播放书签字幕”时，旧循环重载与新分段更新交叉的问题。
- 播放完成事件会冻结配置代次；字幕范围、音频或书签分段变化后，晚到的旧循环任务会直接失效。
- 定位弹窗改用当前音频在 ViewModel 中的权威字幕/书签数据，不再依赖播放服务可能晚一帧的字幕快照。
- 修复组合切换后定位页出现额外书签标记、与播放条书签段数不一致的问题。

## v2.0.3 更新

- 定位弹窗的“全部字幕”现在始终来自当前音频的完整字幕列表，不受“仅播放书签字幕”播放范围过滤影响。
- 定位弹窗每行对应一条独立字幕，书签图标只看该条字幕自身状态，修复“仅看书签”中图标仍为灰色的问题。
- 点击字幕行按字幕时间直接跳转；可在完整列表中快速为更多字幕添加书签。
- 修复单曲循环沿用完成时的最后分段位置、只循环最后一句的问题；整曲完成后明确从第 1 段、第 1 遍重新加载。

## v2.0.2 更新

- “定位片段”新增“全部片段/仅看书签”筛选，无需改变实际播放范围即可集中查看书签字幕。
- 定位弹窗右侧新增可拖动的快速滚动条，长字幕列表可快速定位。
- 全部“收藏字幕”用语统一为“字幕书签”，“仅播放收藏字幕”改为“仅播放书签字幕”。
- 修复连续切换音频时字幕、书签读取相互穿插，导致字幕串到其他音频或书签显示错误的问题。
- 切换到仅播放书签字幕时重新读取当前音频的最新书签，修复已有书签却误报为空。
- 修改列表播放、倍速等无关设置时不再错误触发书签校验。
- 列表播放新增“单曲循环”，适合循环播放少量书签字幕。

## v2.0.1 更新

- “定位片段”现在直接显示每段字幕的书签状态，并可在弹窗内收藏或取消收藏后再跳转。
- 播放列表标题最多显示两行；删除入口移入“更多操作”，并增加二次确认，同时明确不会删除手机中的原文件。
- 将含糊的“无法生成播放片段”改为按具体原因提示音频时长、字幕、收藏范围或分段设置。
- 修复播放服务在定时到期后重建时丢弃到期时间的问题，重建后的首次检查会继续执行停止。
- 真机核查“立即停止”和“当前段结束”：前者到点立即停止，后者在当前段边界停止，均不会自动进入下一遍或下一段。

## v2.0.0 更新

- 应用显示名称由“回声英语”改为“回声复读”，不再限定学习语言；包名保持不变，可直接覆盖升级并保留已有数据。
- 新增字幕收藏/书签：当前字幕和展开后的每句字幕都可收藏或取消，重启应用后仍保留。
- 按字幕分段新增“仅播放收藏字幕”，自动跳过未收藏内容；没有书签时会提示先收藏。
- 修复多个字幕合并在同一播放片段时，当前字幕一直停留在第一句的问题；字幕现在按真实播放位置切换。
- 加大未展开状态的字幕显示区域，同时保留展开、滚动定位和点击跳转能力。
- 播放命令日志新增来源标识，便于区分播放页操作和其他暂停原因。
- 数据库升级到 v3，新增字幕书签表并保留原播放列表、字幕偏移和学习进度。

## v1.7.9 更新

- 重新打开应用时自动恢复上次播放条目并进入复读页，不再要求从播放列表重新查找和点开。
- 后台播放服务仍存活时直接重新连接现有播放器，不重新装载、跳转或打断音频，并保持原播放/暂停状态与重复遍数。
- 播放进程被系统清理后，恢复上次保存的绝对位置、所在分段和重复遍数，但默认保持暂停，避免冷启动突然发声。
- 播放进度和轻量级会话状态改由媒体播放服务持续保存；退出界面后仍能更新进度。
- 冷启动暂停恢复使用普通服务启动路径，避免把暂停装载错误地作为前台播放启动。
- 手动从播放列表打开音频仍立即播放；分段、字幕、睡眠定时和锁屏后台播放规则保持不变。

## v1.7.8 更新

- 修复“当前段结束后停止”定时到期时被误标记为整首播放完成、继而自动切换下一首的问题。
- 新增独立的睡眠定时停止原因，定时停止只暂停播放并保存当前位置，不再触发播放列表自动前进。
- 已运行的播放服务新增内部命令分发，锁屏或后台自然切换下一首时不再重复调用 startForegroundService。
- Android 12 及以上遇到后台前台服务启动限制时会捕获异常并给出提示，避免应用主线程闪退。
- 新增自然完成、睡眠定时停止和未完成状态的播放列表导航回归测试。
- 保留字幕同步校准、字幕前后补偿、精确分段复读及锁屏后台播放等既有能力。


- 新增按音频独立保存的“字幕同步校准”，支持整体提前或延后字幕，范围 ±10 秒、精调步长 0.1 秒。
- 字幕偏移统一作用于当前字幕、完整字幕列表、字幕跳转、按字幕分段、仅字幕片段和固定时长片段文本匹配。
- 时间处理顺序统一为“原始 SRT → 整体偏移 → 音频边界裁剪 → 字幕前后补偿 → 播放分段”，避免重复应用偏移。
- 数据库升级到 v2，仅增加默认值为 0 的 subtitleOffsetMs 列，保留旧播放列表、字幕对应关系和学习进度。
- 设置即时生效：字幕模式回到调整后当前字幕片段起点，固定时长模式保持当前音频位置和播放/暂停状态。
- 修复倒数第二遍切换到最后一遍时停顿明显变长的问题；最后一遍继续复用已准备的当前媒体窗口。
- 下一段改为在最后一遍开始后通过 `addMediaItem()` 动态追加并预缓冲，不再为最后一遍执行 `setMediaItems()` 和完整 `prepare()`。
- 自动转换改用动态媒体项索引，消费预加载片段后清理已播放项，连续多个片段均可稳定工作。
- 新增重复边界、实际转换耗时、窗口复用、队列追加和 `prepare()` 调用状态日志。
- “按字幕 → 仅播放字幕片段”新增字幕前置补偿与后置补偿，可选 0 / 0.2 / 0.3 / 0.5 / 0.8 秒，默认 0.3 / 0.5 秒。
- 补偿范围严格裁剪在音频时长内；相邻补偿区相交时共享原字幕间隙中点，确保片段不重叠，较大的无字幕区域仍会跳过。
- 补偿设置持久化并立即应用到当前音频，同时回到当前字幕片段的新起点，保持原播放/暂停状态。
- 仅字幕模式的当前字幕卡在前置补偿期间也显示对应句子，便于跟读定位。
- 新增独立的前置/后置补偿图标和分段诊断日志；完整字幕时间线及固定时长模式保持原逻辑。
- 固定时长与字幕分段统一规范化，排序、裁剪并消除区间重叠。
- 重复播放时从分段起点开始，不再把保存的段内进度当作第一遍起点。
- 同段重复复用已准备的媒体项，避免每遍重新创建 MP3 解码入口。
- 当前段最后一遍和下一段第一遍使用两个预缓冲的独立裁剪媒体项；设置的静音间隔只用于同段重复。
- 为 VBR MP3 启用 `Mp3Extractor.FLAG_ENABLE_INDEX_SEEKING` 和 `SeekParameters.EXACT`，提高较后位置和分段边界的准确度。
- 重复间隔期间保留 mediaPlayback 前台服务，并短时持有 `PARTIAL_WAKE_LOCK`，间隔结束后立即释放。
- 系统媒体会话使用整条音频的绝对进度，支持系统上一段、下一段和点击通知返回应用。

## 本地构建

配置 JDK 17 与 Android SDK 后，在项目根目录执行：

```powershell
.\gradlew.bat --no-daemon --max-workers=1 testDebugUnitTest assembleDebug
```

如 D8 在依赖合并阶段内存不足，可临时设置：

```powershell
$env:GRADLE_OPTS='-Xmx4096m -Dfile.encoding=UTF-8'
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`。

这是 Debug 测试版本，正式上架前应使用独立 Release 证书签名。
