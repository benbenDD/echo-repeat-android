# 回声英语 v1.1.0

## 本次修复

- 播放页新增“当前段”和“整段音频”两个独立进度条。
- 整段音频进度条支持拖动到任意绝对时间，并自动切换对应片段和字幕。
- 新增“选择片段”，可以从可滚动列表跳转到任意片段，当前片段紫色高亮。
- 修改每段时长后立即重新分段，并尽量保持当前绝对播放位置。
- 修改重复次数后立即应用到后台播放服务，重复计数重置为第1次。
- 修改播放速度后声音立即变速，不需要返回播放列表。
- 修复5秒、10秒、重复1次和0.75x无法显示选中的问题。
- 所有选中项统一使用紫色边框和浅紫色背景。
- 复读页重新布局，字幕区域使用剩余空间，不再保留下半部分大面积空白。
- 字幕改为可上下滑动列表，当前字幕紫色高亮。
- 播放时自动跟随当前字幕；用户手动滚动后暂停自动跟随2.5秒。
- 点击任意字幕可跳转到对应播放位置。
- 字幕模式下“每段时长”会显示为不可用。

## 使用方法

1. 安装 `EchoEnglish-v1.1.0-debug.apk`。如果手机已安装1.0.0，可直接覆盖安装，播放列表数据应继续保留。
2. 进入复读页后，上方大区域可以上下滑动浏览字幕，点击字幕即可跳转。
3. 点击“选择片段”可快速跳转到指定分段。
4. “当前段”进度条只在当前片段内移动；“整段音频”进度条可以跳到音频任意位置。
5. 在设置页修改时长、重复次数或播放速度会立即应用，不需要重新打开音频。
