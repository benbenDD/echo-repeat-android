# 回声复读 v2.0.5

v2.0.5 针对锁屏、分段间隔和自动复读期间的后台播放可靠性增加前台服务保持策略与本地诊断记录。

## 后台播放

- 播放任务处于自动复读、分段切换或分段间隔时，继续保持媒体前台服务，不再把播放器短暂的非播放状态误判为用户暂停。
- Media3 请求更新播放通知时，会根据真实播放任务状态决定是否保持前台，降低小米系统在锁屏后清理服务的概率。

## 本地播放诊断

- 新增应用内部播放诊断日志，记录服务创建/销毁、播放状态、命令来源、通知前台状态和睡眠定时停止。
- 日志采用两个最大 256 KB 的轮换文件并异步写入，不会无限增长，也不会阻塞音频播放。

## 验证

- 20 个单元测试类全部通过。
- Xiaomi M2102K1C 覆盖安装成功并保留原数据。
- 后续设备日志进一步发现：锁屏自动连播在“上一首自然结束、下一首载入”交接窗口仍可能短暂退出前台，该问题在 v2.0.6 修复。
