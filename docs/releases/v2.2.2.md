# 回声复读 v2.2.2

## 本次更新

- “上一段”始终跳转到上一段开头，取消播放超过 3 秒就重播本段的规则。
- 改善蓝牙耳机控制，统一播放、暂停、上一段和下一段的处理；分段间隔和跟读期间也可暂停、恢复。
- 修复定时到期后重新打开应用，第一次点击播放又立即停止的问题；清理已到期的旧定时与遗留的待停止标记，保留尚未到期的定时。
- 播放列表支持整页滚动，横屏时可查看文件夹与条目；横屏复读页可滚动到进度条和全部播放控制。
- 定时结束提示改为“定时结束，已停止播放”，同时适用于立即停止与当前段结束两种模式。

## 同时包含自 v2.1.6 以来的改进

- 全局字幕搜索：在播放列表输入台词或词汇，可跨音频检索，支持全部播放列表、当前文件夹、当前音频筛选。
- 全局搜索结果显示所属音频、字幕序号、毫秒时间与关键词高亮；点击只定位并保持暂停，按播放键后开始播放。
- 搜索结果已经有书签时保留仅书签范围；未加书签时临时使用全部字幕片段定位，保存的书签设置保持不变。
- 在定位字幕窗口点击字幕，保留原有播放意图，包括正常分段间隔和跟读静音阶段。
- 修复全局搜索查询可能闪退的问题。
- 改善锁屏媒体控制的缓冲状态显示，并对裁剪分段结尾卡住、显示播放却无声的情况加入自动恢复。
