# v2.3.0 多点字幕校准

当字幕在开头对齐、后面逐渐偏离，或中途突然错位时，现在可以为同一音频设置多个校准点。

## 使用方法

1. 打开音频，从学习设置 → 分段与字幕 → 多点字幕校准 → 管理校准点进入。点击“添加校准点 · 选择字幕”，可搜索台词或输入序号选择一句容易辨认的台词。
2. 选择原始字幕序号，填写该句声音实际开始的音频时间，例如 `43:00.810`。播放到准确位置时也可以读取当前播放位置，再微调输入。
3. 保存后在后面另选一句重复操作。
4. 逐渐错位选择“渐进校准”；因删减、插入造成突然错位选择“分区校准”。

## 时间规则

- 渐进校准：一个点时整体平移；多个点之间线性插值；首点之前和末点之后沿用最近点的时间差。
- 分区校准：首点之前保持原始时间；每个点起应用该点时间差，单句持续时间保持不变。
- 整体提前／推后在多点校准之后生效，可以继续微调。
- 校准点按音频独立保存，不修改原始字幕；更换匹配的字幕文件会清除该音频旧校准点。
- 删除校准点、切换模式会立即重新计算字幕及分段。清除全部校准点不会删除书签，也不会清除整体偏移。
- 校准作用于字幕时间，不会拉伸或修改音频内容；缺失或多出的台词本身不能靠时间校准补齐。
- 渐进／分区模式的选中项使用紫色边框与底色，未选中项不显示边框；定位片段列表不显示逐句校准按钮。
