# 回声复读 v2.0.2

v2.0.2 集中修复字幕与书签状态错位，并增强书签片段定位和循环播放。

## 定位片段

- 新增“全部片段”和“仅看书签”两个筛选入口。
- 查看书签片段不再要求先把播放范围切换为“仅播放书签字幕”。
- 右侧新增可拖动快速滚动条，可直接拖到较后位置。
- 每段继续显示当前书签状态，并可直接添加或取消书签。

## 字幕与书签可靠性

- 音频切换时，字幕解析、字幕偏移和书签读取改为同一条串行状态更新，避免两条音频的数据相互覆盖。
- 添加或取消书签时核对当前音频，旧音频的延迟操作不会修改新音频的书签显示。
- 切换到“仅播放书签字幕”时从数据库重新读取当前音频的最新书签，不再依赖可能过期的内存结果。
- 只有分段方式或字幕播放范围发生变化时才执行字幕/书签校验；列表播放等无关选项不再被拦截。

## 命名与列表播放

- “仅播放收藏字幕”更名为“仅播放书签字幕”，与书签图标一致。
- 相关提示和按钮统一使用“书签”。
- 列表播放新增“单曲循环”，当前音频播放完成后从头重新播放；与仅播放书签字幕组合时，可持续循环少量重点内容。

## 验证

- 133 项单元测试通过，0 失败、0 错误、0 跳过。
- 新增回归测试确认修改列表播放模式不会触发字幕书签校验。
- 新增单曲循环导航测试，播放完成后仍选择当前音频。
- Xiaomi M2102K1C 覆盖安装并保留既有播放列表与书签。
