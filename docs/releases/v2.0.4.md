# 回声复读 v2.0.4

v2.0.4 修复单曲循环期间切换字幕播放范围时的并发状态交叉。

## 播放范围切换

- 每次音频、字幕范围或书签分段变化都会产生新的播放配置代次。
- 单曲完成事件在发生当刻记录自己的代次；保存进度期间如果用户切换范围，旧循环重载会被丢弃。
- 旧的完整字幕循环任务不能覆盖后设置的书签播放队列，避免短时间出现两套播放流程交错。

## 定位片段书签

- 定位弹窗不再使用媒体播放服务异步回传的上一帧字幕快照。
- 当前音频的字幕时间、文本和书签状态由同一份 ViewModel 数据提供。
- 添加、取消、重新读取书签以及字幕偏移变化后都会同步刷新这份数据。

## 验证

- 134 项单元测试通过，0 失败、0 错误、0 跳过。
- Xiaomi M2102K1C 覆盖安装成功，版本为 `2.0.4 (24)`。
- 真机按照“仅播放字幕片段 + 单曲循环 → 播放末尾时切换仅播放书签字幕”完成组合测试。
- 切换只产生一次书签分段更新；完成后只产生一次单曲重载，并从第一个书签开始。
- “仅看书签”显示 4 个已加书签、0 个灰色项，与播放条 4 个书签段一致。
