# 回声复读 v2.0.7

v2.0.7 新增当前音频的字幕全文搜索，方便通过记得的一句台词或关键词快速定位播放位置。

## 字幕搜索

- “定位片段”弹窗顶部新增字幕搜索框，输入台词或关键词后实时筛选。
- 搜索使用当前音频的完整字幕，不受“仅播放书签字幕”范围限制。
- 支持中文包含匹配，英文搜索忽略大小写。
- 自动归一化换行、连续空格和搜索词首尾空格。
- 可与“仅看书签”组合，只搜索已经添加书签的字幕。
- 搜索结果保留原字幕序号、起止时间和书签状态。
- 点击结果直接跳转到对应字幕位置；可一键清空并恢复完整列表。
- 无匹配结果时，根据全部字幕或书签字幕范围显示清晰提示。
