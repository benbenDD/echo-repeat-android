# 回声复读 v2.0.0

v2.0.0 将应用从英语专用定位扩展为通用的分段听读工具，并加入字幕学习书签。

## 新功能

- 应用显示名称改为“回声复读”，可用于任意语言、课程或其他带字幕音频。
- 当前字幕和完整字幕列表均可添加或取消书签，收藏结果按音频持久保存。
- 按字幕分段时可选择“仅播放收藏字幕”，自动跳过其他字幕。

## 修复与体验改进

- 修复多个字幕落在同一播放片段时，当前字幕始终显示第一句的问题。
- 未展开的当前字幕区域增高，长句更易阅读。
- 播放页发出的播放/暂停命令会记录明确来源，便于后续诊断。

## 升级说明

- 可直接覆盖安装 v1.7.10，无需卸载。
- 包名保持 `com.echoenglish.app`，原播放列表、导入记录、字幕偏移、设置和播放进度均保留。
- 数据库会从 v2 自动升级到 v3，并创建字幕书签表。

## 验证

- 127 项单元测试通过，0 失败、0 错误、0 跳过。
- Xiaomi M2102K1C（Android 14）覆盖安装并启动成功，版本为 `2.0.0 (20)`。
- 收藏字幕后强制结束并重启应用，书签仍保留。
- 选择“仅播放收藏字幕”后，测试音频从 1251 个字幕片段筛选为 1 个收藏片段。

## 关于一次“定时未结束却暂停”的诊断

手机日志显示该次暂停发生前有一次完整屏幕触摸，随后播放页发送 `TOGGLE` 并正常暂停；约 83 秒后 MIUI 才清理已处于空闲状态的播放服务。此次不是定时器提前触发，也不是系统先杀死后台播放。
