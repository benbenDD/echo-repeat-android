# 回声复读 v2.0.6

v2.0.6 修复锁屏状态下自动连播换曲时，媒体服务因短暂退出前台而被系统清理的问题。

## 锁屏自动换曲

- 一首音频自然结束后增加 15 秒播放列表交接保护期，在下一首载入前继续保留已有前台播放状态。
- 下一首开始播放后直接接管原前台服务，避免锁屏后台重新申请前台服务被 Android 或小米系统拒绝。
- 用户主动暂停、睡眠定时停止或播放错误会立即取消保护，停止后的应用不会长期驻留。

## 诊断记录

- 增加播放列表交接保护开始、取消和到期记录，后续可直接区分自然换曲、主动停止与系统清理。
