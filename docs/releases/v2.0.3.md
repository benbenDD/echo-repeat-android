# 回声复读 v2.0.3

v2.0.3 修复书签播放范围下的定位列表和单曲循环起点。

## 完整字幕定位

- 即使当前选择“仅播放书签字幕”，“全部字幕”仍展示当前音频的完整字幕文件，不再只显示播放队列中的书签片段。
- 可直接在完整字幕列表中浏览并添加新书签，无需先退出书签播放模式。
- 每一行按自己的字幕编号、时间和文本显示，点击后按该字幕的时间位置跳转。

## 书签状态

- “仅看书签”严格按单条字幕的书签状态筛选。
- 图标只读取该条字幕自身的书签标记，不再受字幕前后补偿或相邻字幕重叠影响。
- 真机验证中“仅看书签”可见 6 条字幕全部显示已添加书签，灰色未书签图标为 0。

## 单曲循环

- 单曲播放完成后不再复用最后一段的保存位置。
- 循环重载固定使用第 1 段、第 1 遍和起始位置，再由当前播放范围定位第一个可播放片段。
- 真机测试中，最后片段 `5,043,864ms` 播放完成后，新窗口从第一个片段 `49,070ms` 开始。

## 验证

- 133 项单元测试通过，0 失败、0 错误、0 跳过。
- Xiaomi M2102K1C 覆盖安装成功，版本为 `2.0.3 (23)`。
- 书签播放模式下的定位列表显示完整字幕序号，并保留“仅看书签”和快速滚动条。
