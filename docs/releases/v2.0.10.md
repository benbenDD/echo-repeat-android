# 回声复读 v2.0.10

v2.0.10 在 v2.0.9 跟读功能基础上重构设置交互，并完善定位片段和跟读字幕体验。

## 设置页折叠分类

- 设置页默认显示“分段与字幕”“复读与跟读”“连续播放与定时”三个分类。
- 点击分类在同一页面展开，再次点击收起；切换分类时原分类自动收起。
- 一级分类高亮，子选项缩进并带层级色条，强化上下级关系。
- 展开状态和滚动位置在切换主页面后仍会保留。
- 切换展开分类时自动保证分类标题和第一个子选项完整可见。
- “分段间隔”归入“分段与字幕”；按字幕分段时摘要显示字幕播放范围。

## 定位片段优化

- 定位片段弹窗调整为约 92% 屏幕宽度。
- “全部字幕/仅看书签”使用紫色实心选中态；未选中项使用无强调边框的浅灰背景。

## 跟读字幕同步

- 跟读静音开始时，字幕时间轴回到当前片段开头。
- 跟读过程中字幕按有声播放时相同的节奏切换。
- 暂停跟读时字幕同步暂停，继续后接着推进。
- 字幕使用跟读开始时的播放倍速换算，避免途中修改倍速导致跳动。
