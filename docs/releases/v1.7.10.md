# Echo English v1.7.10

v1.7.10 是基于 v1.7.9 的问题修复版本，重点修复播放恢复和睡眠定时停止。

## 修复内容

- 修复播放服务被系统或 MIUI 最近任务清理后，重新进入应用偶尔点击播放没有反应、进度归零的问题。
- 播放服务缺失时，应用会使用已保存的音频、字幕分段、播放位置和重复序号重新建立完整播放来源，不再用单独的播放命令启动空服务。
- 回到应用前台时只恢复为暂停状态，不会在用户没有操作时自动播放；用户主动点击播放后才会开始播放。
- 修复“当前段结束后停止”定时到期后，播放器又把结束事件当作正常分段边界并继续下一遍复读的问题。
- 定时停止后会阻止重复、分段间隔、下一段和播放列表自动跳转；用户仍可主动点击播放重新开始。

## 升级说明

- 可以直接覆盖安装 v1.7.9，无需卸载旧版本。
- 播放列表、导入记录、播放设置和已保存进度会保留。
- v1.7.9 及更早版本的 APK、源码包和 Release 不会被覆盖或删除。
