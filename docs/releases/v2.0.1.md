# 回声复读 v2.0.1

v2.0.1 改进片段定位、播放列表管理和睡眠定时器的可靠性。

## 片段定位与书签

- “跳转到指定片段”列表会显示每段是否已经收藏。
- 可在定位弹窗中直接收藏或取消该段包含的字幕，再点击片段跳转播放。
- 没有字幕的固定时长片段会明确说明不能添加字幕书签。

## 播放列表

- 较长的音频标题最多显示两行，超出后再省略。
- 移除入口由直接删除图标改为“更多操作 → 从播放列表移除”，减少误触。
- 移除前必须再次确认；对话框明确说明只移除应用记录，不删除手机中的音频和字幕文件。

## 更清楚的错误提示

无法生成片段时，会根据实际原因分别提示：无法读取音频时长、没有有效字幕、没有收藏字幕，或需要调整分段方式/时长。

## 睡眠定时器

- 修复播放服务在定时到期后重建时忽略已到期时间的问题。
- “立即停止”在到点时直接进入睡眠定时终止状态。
- “当前段结束”到点后只完成正在播放的这一段，并在边界停止，不进入下一遍或下一段。

## 验证

- 130 项单元测试通过，0 失败、0 错误、0 跳过。
- Xiaomi M2102K1C 覆盖安装成功，系统报告版本 `2.0.1 (21)`。
- 真机一分钟“立即停止”于到期当秒停止。
- 真机一分钟“当前段结束”在到期后的当前段边界停止，没有触发下一遍或下一段。
