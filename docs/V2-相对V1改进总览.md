# 回声复读 V2 相对 V1 改进总览

V2 在 V1 已具备的 MP3/SRT 导入、固定时长/字幕分段、重复播放、倍速、睡眠定时和后台播放基础上，重点扩展了学习标记、字幕定位、播放状态一致性及锁屏可靠性。

## 1. 产品定位与名称

- 应用由“回声英语”更名为“回声复读”，从英语学习工具扩展为适用于任意语言、课程复习和带字幕音频精听的通用工具。
- 包名保持不变，可从 V1 直接覆盖升级，播放列表、字幕关联、字幕偏移、设置和学习进度继续保留。

## 2. 字幕书签与重点复习

- 可在当前字幕、展开字幕列表和定位片段弹窗中添加或取消书签，并按音频持久保存。
- 支持“仅播放书签字幕”，自动跳过其他内容；无书签时提供明确提示。
- 定位片段提供“全部字幕/仅看书签”筛选，可在完整字幕中继续添加书签。
- 定位列表增加可拖动快速滚动条，适合长音频和大量字幕。
- 列表播放增加“单曲循环”，可持续循环一首音频中的少量重点书签。

## 3. 字幕显示与定位准确性

- 定位片段新增字幕全文搜索，可通过中文或英文台词关键词快速跳转，并可与书签筛选组合使用。
- 修复一个播放片段包含多句字幕时，高亮一直停留在第一句的问题，当前字幕按真实播放位置更新。
- 增大未展开字幕区域，同时保留展开、滚动和点击跳转能力。
- 修复快速切换音频时字幕或书签串到其他文件、已有书签显示灰色、书签数量与播放段数不一致等状态错位。
- 即使正在“仅播放书签字幕”，定位页的“全部字幕”仍显示完整字幕文件，便于继续选择重点内容。

## 4. 播放与循环一致性

- 单曲循环完成后明确从第 1 段、第 1 遍重新开始，不再只循环最后一句。
- 为音频、字幕范围和书签分段引入播放配置代次，避免播放结束重载与用户切换范围同时发生时出现双音频叠加或旧配置覆盖新配置。
- 定位弹窗统一使用当前音频的权威字幕和书签数据，降低播放器异步状态造成的显示偏差。

## 5. 播放列表与交互体验

- 长音频标题最多显示两行。
- 删除入口移入“更多操作”，增加二次确认，并明确只移除应用记录、不删除手机原文件。
- 将“收藏字幕”统一改称“字幕书签”，与书签图标和功能含义保持一致。
- 原本笼统的“无法生成播放片段”改为按音频时长、字幕、书签范围或分段设置给出具体原因。

## 6. 睡眠定时可靠性

- 修复播放服务重建后忽略已到期定时的问题。
- “立即停止”在到点时直接停止；“当前段结束”只完成当前段，不进入下一遍、下一段或下一首。
- 睡眠定时停止拥有独立停止原因，不再被误判为整首自然完成。

## 7. 锁屏后台播放与可诊断性

- 自动复读、分段切换和分段间隔期间持续保持媒体前台服务。
- 修复锁屏自动连播时，上一首结束与下一首载入之间短暂退出前台、随后被系统清理的问题。
- 新增有容量上限的本地播放诊断记录，可区分用户操作、睡眠定时、播放错误、自然换曲和系统销毁，不会无限占用存储空间。

## V2 版本脉络

- v2.0.0：通用化命名、字幕书签、仅播放书签字幕、字幕高亮修复。
- v2.0.1：定位页书签操作、播放列表防误删、错误提示和睡眠定时修复。
- v2.0.2：书签筛选、快速滚动、字幕/书签隔离和单曲循环。
- v2.0.3：完整字幕定位、书签状态修复和循环起点修复。
- v2.0.4：解决循环重载与字幕范围切换的并发状态交叉。
- v2.0.5：自动播放过程前台服务保持与本地诊断日志。
- v2.0.6：修复锁屏自动换曲交接窗口被系统清理。
- v2.0.7：新增当前音频字幕全文搜索和书签内搜索。
