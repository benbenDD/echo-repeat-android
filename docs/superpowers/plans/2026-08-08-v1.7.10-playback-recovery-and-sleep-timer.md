# Echo English v1.7.10 Playback Recovery and Sleep Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.7.10 so a missing playback service is rebuilt from the saved session instead of receiving an empty command, and sleep-timer expiry cannot restart repeat automation.

**Architecture:** Keep track preparation in `MainViewModel` and expose only a lightweight prepared-source health signal from `PlaybackService`. A pure `PlaybackCommandRecoveryPolicy` decides whether a missing command should recover playing, recover paused, or be ignored; `PlaybackServicePolicy` supplies the terminal sleep-stop guard used at both ExoPlayer boundary entry points.

**Tech Stack:** Kotlin, Android ViewModel/coroutines, Media3 ExoPlayer/MediaSessionService, Room/DataStore persistence, JUnit 4, Gradle 8.2.1, JDK 17.

## Global Constraints

- Base all work on tag `v1.7.9` / commit `10b2685` in branch `codex/v1.7.10-playback-recovery`.
- Set Android version name to `1.7.10` and version code to `19`.
- Do not change segment generation, repeat boundaries, subtitle timing, navigation UI, dependencies, or database schema.
- Do not delete, rename, overwrite, or retag any v1.7.9 or earlier artifact.
- Foreground recovery must load paused; only an explicit play/toggle may recover with autoplay.
- Every production behavior change starts with a failing regression test.

```kotlin
sealed interface PlaybackCommandRecoveryDecision {
    data object Dispatch : PlaybackCommandRecoveryDecision
    data class Recover(val autoPlay: Boolean) : PlaybackCommandRecoveryDecision
    data object Ignore : PlaybackCommandRecoveryDecision
}

object PlaybackCommandRecoveryPolicy {
    fun decide(
        action: String?,
        sourceReady: Boolean,
        hasSelectedTrack: Boolean
    ): PlaybackCommandRecoveryDecision {
        if (sourceReady) return PlaybackCommandRecoveryDecision.Dispatch
        if (!hasSelectedTrack) return PlaybackCommandRecoveryDecision.Ignore
        return when (action) {
            PlaybackContract.ACTION_TOGGLE ->
                PlaybackCommandRecoveryDecision.Recover(autoPlay = true)
            PlaybackContract.ACTION_SEEK,
            PlaybackContract.ACTION_SEEK_ABSOLUTE,
            PlaybackContract.ACTION_SEEK_SEGMENT,
            PlaybackContract.ACTION_NEXT,
            PlaybackContract.ACTION_PREVIOUS,
            PlaybackContract.ACTION_RESTART ->
                PlaybackCommandRecoveryDecision.Recover(autoPlay = false)
            else -> PlaybackCommandRecoveryDecision.Ignore
        }
    }
}
```
