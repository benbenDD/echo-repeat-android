# v1.7.9 Playback State Restoration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore the last playback item automatically, reconnect without interruption when the playback service survives, and restore a killed process at the saved position in a paused state.

**Architecture:** Add pure startup/session policies that can be unit-tested, persist a lightweight playback session from `PlaybackService`, and make `MainViewModel` perform one startup restore after settings load. A live `PlaybackBus` snapshot wins over disk; otherwise the saved session and `lastTrackId` rebuild the player with an explicit non-autoplay load.

**Tech Stack:** Kotlin 1.9, Android SDK 34, Jetpack Compose, Media3 ExoPlayer/MediaSessionService, DataStore, SharedPreferences, custom SQLite DAO, JUnit 4, coroutines.

## Global Constraints

- Version must be `versionName = "1.7.9"` and `versionCode = 18`.
- A surviving playback service must not receive `ACTION_LOAD`, seek, pause, or restart during UI reconnection.
- A process-death restore must load the saved item and exact position but remain paused.
- A manual playlist open must continue to start playback immediately.
- Existing segment boundaries, subtitle timing, sleep-timer semantics, and playlist order must not change.
- Do not add new external dependencies.

- [ ] **Step 3: Implement the minimal decision model**

```kotlin
sealed interface PlaybackRestoreDecision {
    data class AttachToActive(val trackId: Long) : PlaybackRestoreDecision
    data class LoadPaused(val trackId: Long) : PlaybackRestoreDecision
    data object None : PlaybackRestoreDecision
}

object PlaybackRestorePolicy {
    fun decide(activeMediaId: String, activeSegmentCount: Int, lastTrackId: Long): PlaybackRestoreDecision {
        val activeId = activeMediaId.toLongOrNull()?.takeIf { it > 0 && activeSegmentCount > 0 }
        return when {
            activeId != null -> PlaybackRestoreDecision.AttachToActive(activeId)
            lastTrackId > 0 -> PlaybackRestoreDecision.LoadPaused(lastTrackId)
            else -> PlaybackRestoreDecision.None
        }
    }
}
```

- [ ] **Step 1: Add a startup restore path after the first settings emission**

Extract track preparation from `openTrack` into a suspend helper that reads cues, adjusts subtitle timing, and builds segments without sending a service command. On the first settings emission only, read `lastTrackId.first()` and decide:

```kotlin
when (val decision = PlaybackRestorePolicy.decide(
    playback.value.mediaId,
    playback.value.segmentCount,
    lastTrackId
)) {
    is PlaybackRestoreDecision.AttachToActive -> prepareAndSelect(decision.trackId, sendLoad = false)
    is PlaybackRestoreDecision.LoadPaused -> prepareAndSelect(decision.trackId, sendLoad = true, autoPlay = false)
    PlaybackRestoreDecision.None -> Unit
}
```

For cold restore, use the matching persisted session position/segment/repeat if present; otherwise use `TrackEntity` progress. Pass exact-position restore and autoplay false. For an unavailable or missing saved track, leave `current` null and expose a short message.

`openTrack(track)` must call the same helper with `sendLoad = true`, `autoPlay = true`, `restoreExactPosition = false`, and repeat index 1. Continue saving `lastTrackId` only after a valid track is selected.
